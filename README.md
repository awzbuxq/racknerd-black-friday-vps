## 按用途选档：1GB 到底够不够

1GB 档适合单用户代理、监控探针、纯静态小站、练手 Linux。跑 WordPress 装一堆插件，内存会顶到天花板，这不是配置不够用，是选错了档。

2.5GB 是这批里的平衡点。2 核 2.5GB 跑 Docker、装宝塔、挂两三个轻量服务都不吃紧，第一次买 VPS 又不想太抠的话选这档，容错空间比 1GB 大得多。

4GB 起才谈得上有建站余量。3 核 4GB 撑日均几千 PV 的 WordPress 没问题，跑个轻量数据库也够。

6GB 和 8GB 面向的是小团队、爬虫、轻量后端、游戏服务器、虚拟主机再分销这类场景。8GB 那档给到 20TB 月流量，是五档里流量最宽的一档。

选档还有一个新维度，是官网 ctrl 面板里的一键应用给出的内存门槛：n8n、Coolify 这类 2GB 内存起就舒服；Ollama、LibreChat、AnythingLLM、Hermes Agent 要求至少 4GB；OpenClaw 要求至少 8GB。如果你买机器就是为了跑这些自托管 AI 工具，那 1GB 和 2.5GB 直接排除，别浪费一次不可退款的下单。
